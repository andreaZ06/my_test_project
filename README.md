# 麦富迪狗粮评论风险洞察看板 MVP

这是一个可直接打开的静态 MVP 原型，面向麦富迪品牌运营，模拟完成京东狗粮 SKU 评论抓取、关键词词频统计、环比风险预警、原始评论证据链和飞书机器人查询。

## 已实现

- 总览页：监控 SKU、周期评论量、中差评率、风险关键词、高风险预警。
- SKU 详情页：评分分布、关键词环比变化、原始评论样本、京东评论入口。
- 关键词详情页：近 7 天词频、前 7 天词频、环比变化、跨 SKU 词频和评论证据链。
- 预警中心：低/中/高风险筛选，未查看/已查看状态管理。
- 配置页：SKU 新增、编辑、启停、删除；高敏词库维护；预警阈值配置。
- 飞书模拟：固定指令查询、少量自然语言容错、预警摘要和看板跳转文案。
- 抓取兜底：支持模拟抓取失败，失败时保留上一版历史数据。

## 使用方式

直接用浏览器打开 `index.html` 即可。嵌入飞书时，将页面部署到公司内网或 HTTPS 静态站点，再在飞书自建应用中配置网页入口。

## 真实接口接入点

当前数据来自 `app.js` 中的 `reviewApiAdapter.fetchDailyReviews` 模拟适配器。接入真实京东评论数据时，替换该函数返回值即可，建议返回以下字段：

- `id`：评论唯一 ID，用于去重。
- `skuId`：归属 SKU。
- `content`：评论原文。
- `ratingType`：`good` / `neutral` / `bad`。
- `date`：评论日期，格式 `YYYY-MM-DD`。
- `crawledAt`：抓取日期。
- `user`：脱敏用户标识。
- `keywords`：可由前端或后端分词生成。

## MVP 边界

本版本不做复杂 AI 归因聚类、不做自动工单流转、不做跨平台评论抓取、不做竞品对比。核心目标是验证品牌运营是否能通过看板和飞书预警更早发现评论风险，并快速定位原始评论证据。
